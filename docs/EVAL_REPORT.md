# Synthetic Agent Accuracy Evaluation Report

> [!NOTE]
> This evaluation uses synthetic PDF test data generated by `build_text_pdf`.
> Only rule **R01 (AMOUNT_MISMATCH)** is measured in this benchmark.

## Evaluation Methodology
- **Institution Code:** `EVAL-INST`
- **Total Samples Evaluated:** 40
- **Negative Samples (`EVAL-OK-*`):** 20 (Submitted amount matches PDF amount exactly: ₹50,000.00)
- **Positive Samples (`EVAL-BAD-*`):** 20 (Submitted amount ₹50,000.00, PDF amount injected as ₹99,999.00)
- **Pipeline:** For each sample, the PDF was uploaded via `upload_document`, processed through `run_review_for_deposit`, and checked for open `R01` findings.

## Findings
Rule R01 operates deterministically on cleanly extracted text layers. For digital PDFs generated with valid font and character streams, the rule achieves perfect precision (1.00) and recall (1.00).
